# 🌀 Portal 传送门游戏 Demo

一个用 **Three.js** 实现的第一人称 3D「传送门」玩法 Demo：玩家可放置蓝 / 橙两扇传送门，从一扇进、另一扇出，并保持进入时的动量与方向；包含重力、碰撞、可互动物体与多关卡解谜。

> **完全离线、自包含**——不依赖任何外部 CDN / 在线资源。引擎、纹理、关卡数据全部在项目文件夹内，拷到无网环境也能跑。

---

## ✨ 特性

- **双传送门 + 动量守恒**：左键放蓝门、右键放橙门，穿越时方向 / 速度按门朝向正确翻转。
- **全表面放置**：墙面、地面、天花板、平台均可放门，解锁经典 Portal 的「垂直 ↔ 水平门互换」玩法。
- **实时透视（RTT）**：从一扇门望去能看到另一扇门后的实时画面（Render-to-Texture）。
- **重力 + AABB 碰撞**：自研碰撞解算，玩家与伴侣方块共用。
- **伴侣方块（Companion Cube）**：`F` 键拾取 / 抛投，可当垫脚石站立、也能穿过传送门。
- **5 个解谜关卡 + 选关**：关卡数据外置于 `levels.json`，切换 / 新增关卡只改数据不动逻辑。
- **暂停菜单 / FPS 显示**：`E` 或 `Esc` 呼出菜单（继续 / 选关 / 重开 / 回主界面）。
- **零构建、零 CDN**：经典 `<script src>`，双击 `index.html` 即可在 `file://` 下运行。

## 🎮 操作

| 操作 | 按键 |
|------|------|
| 移动 | `W` `A` `S` `D` |
| 视角 | 鼠标（点击画面锁定指针） |
| 放蓝门 / 橙门 | 鼠标左键 / 右键（限墙面 / 地面 / 天花板 / 平台） |
| 拾取 / 放下方块 | `F` |
| 暂停菜单 | `E` 或 `Esc` |
| 过关后进下一关 | `R` |

## 🚀 运行方式

**方式一 · 一键启动（推荐）**
直接双击 `start_server.bat`，脚本会检查依赖、起本地服务器并自动打开浏览器。

**方式二 · 手动起服务器**
```bash
python -m http.server 8000
# 然后浏览器打开 http://localhost:8000
```

**方式三 · 直接双击**
双击 `index.html` 也能跑（`file://` 下自动回退内置关卡 + 程序化纹理，体验基本一致）。

> 首次跑若缺引擎或纹理，可双击 `下载依赖.bat` / `下载素材.bat` 联网一次补齐（之后离线可用）。

---

## 🧱 技术栈

- **Three.js r159**（本地 UMD 版，`libs/three.min.js`，挂全局 `THREE`）
- 原生 **HTML / CSS / JS**，经典 `<script>` 加载（非 ES module，规避 `file://` 的模块 CORS 限制）
- 音效为纯 **WebAudio** 合成，零外部音频文件

## 📁 项目结构

```
项目-Portal游戏Demo/
├── index.html              ← 入口：UI 外壳 + 按序引 7 个 <script>
├── js/
│   ├── world.js   ← 场景/相机/渲染器/材质/光照/纹理/平台碰撞/buildLevel
│   ├── portal.js  ← 传送门表面/RTT 渲染/虚拟相机矩阵/穿越触发
│   ├── cube.js    ← 伴侣方块物理（抓取/投掷/可站立/穿越）
│   ├── audio.js   ← WebAudio 合成音效（portal/teleport/goal/grab）
│   ├── input.js   ← 指针锁定/鼠标视角/键盘状态
│   └── game.js    ← 主循环/状态机/UI(暂停·选关·FPS)/PG.game.init() 粘合
├── levels.json             ← 关卡数据（5 关，外置）
├── libs/three.min.js       ← 本地 Three.js r159
├── assets/textures/        ← 7 张本地免费纹理（零外部链接）
├── start_server.bat        ← 一键启动本地服务器
├── 下载依赖.bat            ← 联网一次补齐引擎
└── 下载素材.bat            ← 联网一次补齐纹理
```

全局命名空间收口在 `window.PG`（`PG.cfg` 常量、`PG.state` 状态、`PG.world/portal/cube/audio/input/game` 各模块），避免污染全局。
